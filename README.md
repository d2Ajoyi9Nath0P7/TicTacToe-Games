# Tic Tac Toe Game in Java

## Project Overview
This is a console-based Tic Tac Toe game implemented in Java. The game supports two modes:
- Player vs Player (human vs human)
- Player vs AI (human vs computer)

The game uses object-oriented principles with classes representing players, the game board, and the game logic.

## Features
- Play against another human or an AI opponent.
- Simple console input for moves.
- Validates moves and prevents invalid inputs.
- Checks for win conditions: rows, columns, and diagonals.
- Displays the game board after each move.
- Declares winner or draw at the end of the game.

## Technologies Used
- Java
- Object-Oriented Programming

## How to Run
1. Compile all Java files in the `TicTocToe` package.
2. Run the `main` class.
3. Follow on-screen instructions to select the mode and play the game.

## Project Structure
- `main.java` — Entry point of the game, handles game loop and player interaction.
- `tic_tac_toe.java` — Contains board management and win condition checks.
- `player.java` — Abstract class for players.
- `Player1.java` — Represents a human player.
- `AI.java` — Represents the computer player with random move logic.
